# streams-crawl

Расписание спортивных трансляций: обход открытых телепрограмм, поиск прямых
эфиров футбола, баскетбола и тенниса, склейка одинаковых матчей и список
каналов, которые их показывают.

Обход запускается по расписанию в GitHub Actions (`.github/workflows/crawl.yml`)
и работает щадяще: пауза между запросами, один-два прогона в день, окно —
только ближайшие дни. Результат складывается в `results/` и отдаётся сайту.

Запуск сайта локально: `python run_local.py` (нужны зависимости из
`requirements.txt`). Разбор сохранённых страниц без сети: `scripts/parse_pilots.py`.
